# Unity (Mono) — مرجع ENA: Dream BBQ

**مصدر الخبرة:** ENA: Dream BBQ، بإضافة BepInEx 5 لا تعدّل أي ملف أصلي.

## التعرّف

- المجلدات: `<Game>_Data/` و`Managed/Assembly-CSharp.dll`، و`UnityPlayer.dll`.
- **النسخة:** Mono أو IL2CPP. IL2CPP يحتاج BepInEx 6 وأدوات أخرى، ولم يُجرَّب.
- **مكتبات النص الشائعة:**
  - TextMeshPro (TMP)
  - Yarn Spinner أو Ink (للحوار)
  - Febucci TextAnimator (الآلة الكاتبة)
  - I2 Localization أو Unity Localization (جداول)

## حقن النص

- **الحوار في Yarn:** `Yarn.Unity.Localization` يفحص `_runtimeStringTable` قبل الجدول المضمّن، و`AddLocalizedString` تملؤه دون لمس حزمة الحوار.
- **الواجهة:** خطاف Harmony على `TMP_Text.ParseInputText`، النقطة التي تمر بها كل مسارات تعيين النص. البحث بطبقات:
  1. مطابقة تامة.
  2. بلا حساسية لحالة الأحرف. اللعبة تستدعي `ToUpper()`، فلا تشترط مخالفة الحالة.
  3. قواعد نمطية للنصوص المركّبة: `Last Saved: 3 minutes ago`.
  4. «عنوان + بقية»: يُقسم عند أول سطر فقط.
  5. تفكيك بنيوي سطرًا سطرًا مع تقشير الوسوم المحيطة.
- **نصوص في متغيرات Yarn** لا تمر بجدول الترجمة، فاستخرجها منفصلة.
- **وضع تفريغ** يسجّل كل إنجليزي يمر على TMP بلا ترجمة (`dump_en.txt`)، لتلتقط المركّب الذي فات الطبقات.

## الاتجاه مع TMP

```text
المخزن = reverse( bidi( reshape( النص المنطقي ) ) )   مع  isRightToLeftText = true
```

- TMP في وضع RTL يرسم المخزن معكوسًا، فيظهر صحيحًا. ويبقى ترتيب الكلمات منطقيًا، فتعمل الآلة الكاتبة من بداية الجملة، ويعمل اللف، وتُطابَق الأقواس (python-bidi يطبّق L4).
- **رُفض:** المنطقي وحده (يقلب ENA إلى ANE و25 إلى 52)، والبصري مع LTR (يكسر اللف واتجاه الكاتبة).
- **الوسوم** (`<style=...>` و`<wave>` و`{fade}` و`{0}`) وحدات مصمتة.
- **اضبط العلم في الحالتين** (عربي وغير عربي)، فالمكونات يُعاد استعمالها.
- **كاشف العربية حروف فقط:** النظام العربي ينسّق النسب «100 ٪» بعلامة U+061C. استثنِ U+0600–061F وU+0660–066D وU+06F0–06F9.
- **احفظ الحالة الأصلية** للمكوّن في `ConditionalWeakTable`، وأعدها حين يعود نصه غير عربي.

## الخطوط

- **في وقت التشغيل:** `TMP_FontAsset.CreateFontAsset(ttf)`، ثم سجّله احتياطيًا (fallback) في `TMP_Settings` وجداول خطوط اللعبة، مقابل كل خط من خطوط اللعبة.
- **انقل مقاييس خط اللعبة** (`scale` و`ascentLine` و`descentLine` و`lineHeight`) مضروبة بنسبة حجمي العيّنة. بغير ذلك كان العربي أكبر بـ16% وسطره أطول بـ80%.
- **أصل خط مستقل لكل ملف TTF:** مشاركة أصل بين خطين في اللعبة طابقته مرتين، فأفسد ارتفاع سطر الحوار.
- `getFontFeatures = false` على أصولك، واحذف `GSUB/GPOS/GDEF/DSIG` من النسخ المرقعة. النص مشكّل مسبقًا، وTMP بلا GPOS، فالحركة عديمة العرض تقع عند حافة الحرف اليسرى. صحّح إزاحتها في الخط أو اختر خطًا حركاته يمين الأصل.
- **خطوط النظام** تُقرأ من مكانها ولا تُنسخ إلى الحزمة (الرخصة):
  - تصلح: `micross.ttf` و`tahoma.ttf` و`trado.ttf`.
  - تسقط: Calibri وSakkal Majalla.

## التخطيط لكل مكوّن عربي

| البند | المعالجة |
|---|---|
| المحاذاة | Left وJustified وFlush تصير Right. اقرأ القيمة **الحية**، لأن المكوّن نفسه تتغير محاذاته بحسب النمط |
| التحجيم | autosize بحد أعلى = الحجم الأصلي |
| تباعد الأسطر | قِس حبر الخط العربي بعد بنائه، وعوّض عبر `lineSpacing` بسقف 0.35 مربع |
| حجم النص | معامل إعداد يُطبَّق قبل autosize، مع تتبع ما كتبناه حتى لا يتضخم |
| ضغط المحارف | `characterWidthAdjustment = 0`، وإلغاء التباعد السالب |
| التسطير | أنزله إلى `descentLine × 1.25` في خط المكوّن الأصلي |
| حشو الأطلس | 10% للأملس، و5% للنقطي |
| استثناءات | `ui.layout.json` بمسار الكائن (`*`): align وmargin وminScale وwrap وsizeScale، و`mirror` لعكس التصميم حتى بلا عربية (لافتة السعر) |

## BepInEx

- **المدير قد لا يستقبل `Update()` ولا `Start()`** (Awake فقط، والكوروتينات لا تتقدم بلا أي خطأ). أنشئ `GameObject` خاصًا مع `DontDestroyOnLoad`.
- **إعدادات التطوير في ملف cfg:**
  - وضع التفريغ.
  - فحص التخطيط (`diag_tmp.tsv`).
  - جولة آلية تلتقط القوائم.
  - لوحة اختبار الاتجاه (F9–F12).
  - عقدة حوار تجريبية (F7).
- **خطوات البناء:**

```text
parse_yarn_program → extract_strings (en.json + context.md مرتب سرديًا) → extract_ui → extract_yarn_literals
→ next_batch → merge_batches/merge_ui → validate → patch_pixel_font → build_shaped → deploy → package
```
